# CLAUDE.md

Orientation notes for Claude Code (or any AI assistant) working in this repository.

## Project

NBA Front Office Simulator — a portfolio web app where users run an NBA
franchise as GM: manage rosters and the real salary cap, make trades, sign
free agents, and (eventually) get advice from an AI assistant. See
`README.md` for the pitch and tech stack.

## Key docs

- `docs/ARCHITECTURE.md` — engineering rationale behind what's built (data
  model, cap engine, data sourcing decisions, known simplifications).
- `docs/ROADMAP.md` — the actual, current milestone-by-milestone build plan
  and status. This is the source of truth for what's done and what's next.
- `docs/FEATURE_ROADMAP.md` — a long-term list of ~100 possible future
  features. **This is a reference for future planning, not a build
  queue.** Consult it when planning major new development, but don't
  implement anything from it just because it's listed there — prioritize
  based on dependencies, project stability, technical feasibility, and the
  user's explicit instructions at the time.
