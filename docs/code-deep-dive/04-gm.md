# Deep Dive 04 — GM (Career, AI, Expectations, Trade Value)

Folder: `src/lib/gm/`. All pure. Two clusters: (A) the **objective trade-value engine +
CPU personality/identity/needs** that `evaluateTradeOffer` (doc 01) sits on top of, and
(B) the **GM career/accountability system** (expectations → season verdict → owner

# Cluster A — the trade-value engine & CPU character

## `gm/playerTradeValue.ts`

The single objective value of a player, in **cents** (so players and picks sum directly):

```ts
export const UPSIDE_WEIGHT = 0.4;
const CONTRACT_SURPLUS_WEIGHT = 0.5;
const INJURY_STATUS_MULTIPLIER = { HEALTHY: 1, DAY_TO_DAY: 0.97, OUT: 0.85, SEASON_ENDING: 0.6 };
const CAREER_INJURY_DISCOUNT_PER_GAME = 0.002;
const MAX_CAREER_INJURY_DISCOUNT = 0.3;

export function computePlayerTradeValue(input: PlayerTradeValueInput): bigint {
  const rules = getSeasonCapRules(input.season);

  const ageAdjustedScore = Math.min(100, input.overallRating * ageValueMultiplier(input.age));
  const upsideGap = Math.max(0, input.potentialRating - input.overallRating);
  const grossScore = Math.min(100, ageAdjustedScore + upsideGap * UPSIDE_WEIGHT);
  const grossValueCents = BigInt(
    Math.round(Number(rules.salaryCapCents) * scoreToCapFraction(grossScore)),
  );

  const fairValueTodayCents = BigInt(
    Math.round(Number(rules.salaryCapCents) * scoreToCapFraction(ageAdjustedScore)),
  );
  const surplusCents = fairValueTodayCents - input.currentSalaryCents; // bargain (+) vs overpay (−)

  const totalValueCents =
    grossValueCents + BigInt(Math.round(Number(surplusCents) * CONTRACT_SURPLUS_WEIGHT));

  const careerInjuryDiscount = Math.min(
    MAX_CAREER_INJURY_DISCOUNT,
    input.careerGamesMissedToInjury * CAREER_INJURY_DISCOUNT_PER_GAME,
  );
  const totalMultiplier = INJURY_STATUS_MULTIPLIER[input.injuryStatus] * (1 - careerInjuryDiscount);

  const finalValueCents = BigInt(Math.round(Number(totalValueCents) * totalMultiplier));
  return finalValueCents > 0n ? finalValueCents : 0n;
}
```

**The five factors** from the design brief: current production (`ageAdjustedScore`),
age/timeline (`ageValueMultiplier`), **untapped upside** (`upsideGap × 0.4` — potential
counts, but proven production counts more), **contract quality** (surplus vs their
salary, at half weight so a superstar on a slight overpay is still great), and **injury
risk** (current status × a capped career-history discount). All expressed in cents so
it's directly comparable to a pick's value.

## `gm/draftPickTradeValue.ts`

A pick's value in the same cents unit:

```ts
const ASSUMED_ROOKIE_AGE = 20;
const ROUND_2_VALUE_MULTIPLIER = 0.4;
const YEARS_AWAY_DISCOUNT_PER_YEAR = 0.85;

function projectedPickNumber(round: 1 | 2, competitivenessPercentile: number): number {
  const roundSize = CLASS_SIZE / 2;
  return round === 1
    ? Math.round(1 + competitivenessPercentile * (roundSize - 1)) // worst team → pick 1
    : Math.round(roundSize + 1 + competitivenessPercentile * (roundSize - 1));
}

export function computeDraftPickTradeValue(input: DraftPickTradeValueInput): bigint {
  const rules = getSeasonCapRules(input.pickSeason);
  const pickNumber =
    input.overallPickNumber ??
    projectedPickNumber(input.round, input.originalTeamCompetitivenessPercentile);

  const expectedOverall = expectedRatingForPick(pickNumber, OVERALL_AT_PICK_1, OVERALL_AT_PICK_60);
  const expectedPotential = expectedRatingForPick(
    pickNumber,
    POTENTIAL_AT_PICK_1,
    POTENTIAL_AT_PICK_60,
  );

  const ageAdjustedScore = Math.min(100, expectedOverall * ageValueMultiplier(ASSUMED_ROOKIE_AGE));
  const upsideGap = Math.max(0, expectedPotential - expectedOverall);
  const grossScore = Math.min(100, ageAdjustedScore + upsideGap * UPSIDE_WEIGHT);
  let valueCents = BigInt(
    Math.round(Number(rules.salaryCapCents) * scoreToCapFraction(grossScore)),
  );

  if (input.round === 2)
    valueCents = BigInt(Math.round(Number(valueCents) * ROUND_2_VALUE_MULTIPLIER));
  const yearsAway = Math.max(0, input.pickSeason - input.currentSeason);
  valueCents = BigInt(Math.round(Number(valueCents) * YEARS_AWAY_DISCOUNT_PER_YEAR ** yearsAway)); // compounding discount
  return valueCents > 0n ? valueCents : 0n;
}
```

Projects the pick's likely slot from the **original** team's competitiveness (a bad
team's pick is early/valuable), reads the expected rating/potential off the same draft
curve `generateDraftClass` uses, values it like a rookie, then applies the round-2
penalty and a compounding "years away" discount (`0.85^yearsAway`). Reusing `UPSIDE_WEIGHT`
and the draft curve keeps pick and player value on one consistent scale.

## `gm/gmPersonality.ts`

Seven personalities, each a set of **bounded (0.7–1.3) multipliers**:

```ts
export const GM_PERSONALITY_WEIGHTS: Record<GmPersonality, GmPersonalityWeights> = {
  BALANCED: {
    pickValueMultiplier: 1.0,
    youthValueMultiplier: 1.0,
    veteranValueMultiplier: 1.0,
    badContractSensitivityMultiplier: 1.0,
    acceptanceThresholdMultiplier: 1.0,
  },
  WIN_NOW: {
    pickValueMultiplier: 0.75,
    youthValueMultiplier: 0.75,
    veteranValueMultiplier: 1.3,
    badContractSensitivityMultiplier: 0.9,
    acceptanceThresholdMultiplier: 0.95,
  },
  PROSPECT_LOVER: {
    pickValueMultiplier: 1.15,
    youthValueMultiplier: 1.3,
    veteranValueMultiplier: 0.8,
    badContractSensitivityMultiplier: 1.0,
    acceptanceThresholdMultiplier: 1.0,
  },
  PICK_HOARDER: {
    pickValueMultiplier: 1.3,
    youthValueMultiplier: 1.0,
    veteranValueMultiplier: 1.0,
    badContractSensitivityMultiplier: 1.0,
    acceptanceThresholdMultiplier: 1.0,
  },
  // ...AGGRESSIVE, CONSERVATIVE, SALARY_CONSCIOUS...
};

export function pickRandomGmPersonality(rng: () => number = Math.random): GmPersonality {
  return ALL_GM_PERSONALITIES[Math.floor(rng() * ALL_GM_PERSONALITIES.length)];
}
```

These are the `weights` `evaluateTradeOffer` multiplies into asset values (doc 01). They
are deliberately bounded so a genuinely lopsided trade fails for _every_ personality —
personality only tips _close-to-fair_ deals. Assigned once per team at bootstrap and
stable for the save.

## `gm/teamIdentity.ts` & `gm/teamNeeds.ts`

Identity from competitiveness + age:

```ts
export function computeTeamIdentity(
  competitivenessPercentile: number,
  avgRosterAge: number,
): TeamIdentity {
  if (competitivenessPercentile >= 0.8) return "CONTENDER";
  if (competitivenessPercentile >= 0.6) return "PLAYOFF_TEAM";
  if (competitivenessPercentile >= 0.33) return "PLAY_IN_TEAM";
  return avgRosterAge <= 26 ? "REBUILDING" : "TANKING"; // bad + young = building; bad + old = tanking
}
```

Needs from position + rating (best player at a spot, not average):

```ts
export function computeTeamNeeds(roster: TeamNeedRosterPlayer[]): TeamNeed[] {
  const needs: TeamNeed[] = [];
  const hasStarOrBetter = roster.some((p) =>
    ["SUPERSTAR", "STAR"].includes(getPlayerValueTier(p.overallRating)),
  );
  if (!hasStarOrBetter) needs.push("STAR_SCORER");
  if (bestRatingAtPositions(roster, ["PG"]) < 72) needs.push("POINT_GUARD");
  if (bestRatingAtPositions(roster, ["C"]) < 72) needs.push("RIM_PROTECTOR");
  if (bestRatingAtPositions(roster, ["SF", "SG"]) < 72) needs.push("WING_DEFENDER");
  const rotationCaliberCount = roster.filter((p) => p.overallRating >= 65).length;
  if (rotationCaliberCount < 5 + 3) needs.push("BENCH_DEPTH");
  return needs;
}
```

`identity` and `needs` are what the trade AI layers on top of objective value (a
rebuilder over-values youth/picks; a need-filling player gets a bonus). "Shooting" is
deliberately _not_ a need — there's no shot-profile stat to judge it, so it'd be noise.

# Cluster B — GM career & accountability

The season loop: **payroll tier → expectation → actual outcome → verdict → owner
confidence delta → (fired?) → reputation → job market.**

## `gm/payrollTier.ts`

Collapses apron level into 4 spending tiers (expectation-setting needs to tell "paying
some tax" from "hard-capped at the second apron"):

```ts
export function computePayrollTier(apronLevel: ApronLevel): PayrollTier {
  switch (apronLevel) {
    case ApronLevel.UNDER_CAP:
      return "MODEST";
    case ApronLevel.BETWEEN_CAP_AND_TAX:
      return "MODERATE";
    case ApronLevel.TAXPAYER:
      return "SIGNIFICANT";
    case ApronLevel.FIRST_APRON:
    case ApronLevel.SECOND_APRON:
      return "EXTREME";
  }
}
```

## `gm/expectationLevel.ts`

Preseason expectation from spending + roster quality:

```ts
const BASE_INDEX_BY_TIER = { MODEST: 0, MODERATE: 2, SIGNIFICANT: 3, EXTREME: 4 };

export function computeExpectationLevel(
  payrollTier: PayrollTier,
  teamStrength: number,
): ExpectationLevel {
  let index = BASE_INDEX_BY_TIER[payrollTier];
  if (teamStrength >= 80)
    index += 1; // genuinely elite → held higher
  else if (teamStrength <= 65) index -= 1; // expensive-but-mediocre → benefit of the doubt
  index = Math.max(0, Math.min(EXPECTATION_LEVEL_ORDER.length - 1, index));
  return EXPECTATION_LEVEL_ORDER[index]; // DEVELOP_YOUNG_PLAYERS … CHAMPIONSHIP_CONTENTION
}
```

Spending sets the baseline (index 0–4); roster quality nudges ±1. So an expensive
_bad_ roster is judged more gently than an expensive _elite_ one.

## `gm/seasonEvaluation.ts`

The actual result, the verdict, and the confidence swing.

Deriving how far a team got (reuses `PlayoffSeries` rows — no second source of truth):

```ts
export function computeActualOutcome(teamId, madePlayIn, series): ActualOutcome {
  const teamSeries = series.filter(
    (s) => s.higherSeedTeamId === teamId || s.lowerSeedTeamId === teamId,
  );
  if (teamSeries.length === 0) {
    const index = madePlayIn ? 1 : 0;
    return { index, label: OUTCOME_LABEL[index] };
  }
  const latest = [...teamSeries].sort((a, b) => b.round - a.round)[0];
  const won = latest.winnerTeamId === teamId;
  const index = latest.round === 4 ? (won ? 6 : 5) : latest.round + 1; // 0 missed … 6 champion
  return { index, label: OUTCOME_LABEL[index] };
}

export function evaluateSeason(expectationLevel, actualOutcome): EvaluationVerdict {
  const diff = actualOutcome.index - EXPECTATION_LEVEL_ORDER.indexOf(expectationLevel);
  if (diff >= 1) return "EXCEEDED";
  if (diff === 0) return "MET";
  if (diff === -1) return "FELL_SHORT";
  return "DRASTICALLY_FELL_SHORT";
}
```

The confidence swing — verdict × spending amplifier, plus small fan/finance nudges:

```ts
const BASE_CONFIDENCE_DELTA = { EXCEEDED: 8, MET: 2, FELL_SHORT: -8, DRASTICALLY_FELL_SHORT: -20 };
const PAYROLL_DELTA_MULTIPLIER = { MODEST: 0.5, MODERATE: 0.75, SIGNIFICANT: 1.25, EXTREME: 1.75 };
const FINANCIAL_HEALTH_NUDGE = { THRIVING: 2, HEALTHY: 1, STABLE: 0, STRAINED: -2, IN_THE_RED: -4 };

export function computeConfidenceDelta(
  verdict,
  payrollTier,
  fanHappiness?,
  financialHealth?,
): number {
  const base = BASE_CONFIDENCE_DELTA[verdict] * PAYROLL_DELTA_MULTIPLIER[payrollTier];
  const fanNudge = fanHappiness !== undefined ? (fanHappiness - 65) * 0.08 : 0;
  const financialNudge =
    financialHealth !== undefined ? FINANCIAL_HEALTH_NUDGE[financialHealth] : 0;
  return Math.round(base + fanNudge + financialNudge);
}
```

**Key idea:** high spending amplifies _both_ the reward for justifying it and the
punishment for wasting it (×1.75 at extreme payroll vs ×0.5 at modest). The optional
fan/finance nudges are `undefined`-guarded so old call sites that don't pass them are
unaffected — a clean way to extend a function without breaking callers.

## `gm/jobSecurity.ts`

Buckets the running `ownerConfidence` (0–100) into readable levels:

```ts
export function getJobSecurityLevel(ownerConfidence: number): JobSecurityLevel {
  if (ownerConfidence >= 85) return "VERY_SECURE";
  if (ownerConfidence >= 70) return "SECURE";
  if (ownerConfidence >= 50) return "STABLE";
  if (ownerConfidence >= 30) return "UNDER_PRESSURE";
  if (ownerConfidence >= 15) return "HOT_SEAT";
  return "CRITICAL";
}
```

When confidence hits 0, the offseason action fires the GM and ends the league (a
permanent read-only `CareerRecord`).

## `gm/careerRecord.ts`

Turns a finished tenure into a cross-league reputation change + a title:

```ts
export function computeReputationDelta(input: ReputationDeltaInput): number {
  const winPct = input.wins + input.losses > 0 ? input.wins / (input.wins + input.losses) : 0.5;
  const raw =
    input.championships * 15 +
    input.playoffAppearances * 5 +
    Math.round((winPct - 0.5) * 40) +
    (input.endReason === "FIRED" ? -20 : 0);
  return Math.max(-40, Math.min(60, raw)); // clamp
}

export function computeCareerTitle(gmReputation: number): CareerTitle {
  if (gmReputation >= 90) return "HALL_OF_FAME_EXECUTIVE";
  if (gmReputation >= 75) return "RESPECTED_EXECUTIVE";
  if (gmReputation >= 60) return "STEADY_HAND";
  if (gmReputation >= 40) return "JOURNEYMAN_GM";
  if (gmReputation >= 20) return "UNDER_SCRUTINY";
  return "CAUTIONARY_TALE";
}
```

Championships and playoff runs raise `User.gmReputation`; getting fired costs 20. It's
honest about what it _doesn't_ score (individual trades/draft picks) — those need
per-event tracking that doesn't exist, so they're excluded rather than faked.

## `gm/jobMarket.ts` (recap — full file in the code guide)

Reputation gates which teams will hire you, and sets the starting "leash":

```ts
export function computeJobSituation(strengthPercentile: number): JobSituation {
  if (strengthPercentile >= 0.85) return "CONTENDER";
  if (strengthPercentile >= 0.65) return "PLAYOFF_CONTENDER";
  if (strengthPercentile >= 0.4) return "RETOOLING";
  if (strengthPercentile >= 0.2) return "REBUILD";
  return "BOTTOMING_OUT";
}
// REPUTATION_REQUIRED: CONTENDER 70 … REBUILD/BOTTOMING_OUT 0
// STARTING_OWNER_CONFIDENCE: CONTENDER 52 (short leash) … BOTTOMING_OUT 72 (patient)
```

A title contender only hires a proven GM _and_ starts you on a short leash; a rebuild
hires anyone and is patient. `createLeagueAction` enforces the same gate server-side.

## The season pipeline, end to end

```
computePayrollTier(apron) ─┐
                           ├─► computeExpectationLevel ─► (season plays out)
computeTeamStrength ───────┘
   computeActualOutcome(PlayoffSeries) ─► evaluateSeason ─► verdict
      ─► computeConfidenceDelta(verdict, payrollTier, fans, finances) ─► ownerConfidence±
         ─► getJobSecurityLevel; if 0 → fired → computeReputationDelta → User.gmReputation
            ─► computeJobOffer(strengthPercentile, reputation) gates the next job
```

## Interview one-liners

- "Player and pick trade value are both computed in cents on one scale, so a trade is a
  single sum-vs-sum comparison; team direction (personality/identity/needs) is layered on
  top, not baked into the objective value."
- "Owner confidence swings on how the season measured against a spending-scaled
  expectation — high payroll amplifies both praise and punishment — and hitting zero
  fires you and converts the tenure into a permanent career record that changes your
  cross-league reputation."
- "Reputation then gates a job market: a contender only hires a proven GM and on a
  shorter leash, enforced identically on the server."
